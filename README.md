# 单词本 (WordBook)

一个用 Tauri 2 + Vue 3 编写的桌面单词本应用。

## 功能

- **多词库分组**：可创建多个词库（如 CET-6、雅思核心词），单词归属词库，
  支持新建、重命名、删除词库，编辑单词时可更换所属词库
- **手动记录**：录入英文、中文释义（可多条）、美/英音标、备注（例句 / 记忆笔记）
- **总览**：列表查看当前词库全部单词，支持按单词、释义、备注、音标搜索
- **标记掌握**：每个单词可标记 / 取消「已掌握」
- **随机循环**（按当前词库出牌）：
  - 三种模式：英 → 中、中 → 英、中英同显
  - 顺序随机打乱，到末尾后自动重新洗牌循环
  - 可选「仅未掌握」单词循环
  - 翻开答案时同时显示中英文、音标和备注
  - 键盘快捷键：`空格` 翻转、`←` `→` 切换、`M` 标记掌握
- **导入 / 导出**：
  - 「导入 / 导出」针对当前词库，JSON 文件导入导出，去重合并
  - 「备份全部」导出包含词库分组结构的完整备份；导入备份文件时按名称合并词库

## 数据格式

存储文件位于系统应用数据目录（Windows 下为
`%APPDATA%\com.wordbook.app\wordbook.json`），格式如下：

```json
{
  "version": 2,
  "dicts": [
    { "id": "...", "name": "CET-6", "created_at": 1700000000 }
  ],
  "words": [
    {
      "id": "...",
      "dictId": "...",
      "name": "massage",
      "trans": ["按摩"],
      "usphone": "mə'sɑʒ",
      "ukphone": "'mæsɑːʒ; mə'sɑːʒ; -dʒ",
      "note": "备注或例句",
      "mastered": false,
      "created_at": 1700000000,
      "updated_at": 1700000000
    }
  ]
}
```

同时**兼容导入**以下格式：

1. 旧版本应用格式（无 `dicts` 分组，单词会归入当前词库）
2. 外部词库格式（直接数组，应用会自动补全缺失字段）：

```json
[
  {
    "name": "massage",
    "trans": ["按摩"],
    "usphone": "mə'sɑʒ",
    "ukphone": "'mæsɑːʒ; mə'sɑːʒ; -dʒ"
  }
]
```

导出当前词库时使用数组格式（附带全部字段，外部工具可按 `name` / `trans` 读取）；
「备份全部」导出上文的完整格式。

## 开发

```bash
npm install       # 安装依赖（本项目使用 npmmirror 镜像，见 .npmrc）
npm run tauri dev # 开发模式运行
npm run tauri build # 打包安装程序
```
